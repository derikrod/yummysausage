#Projeto Yummy Sausage
## Objetivo

O objetivo e chegar no pão de hot-dog no menor tempo possível usando as plataformas
Durante o percurso a salsicha vai ficando podre. Se o jogador demorar demais não morre mais fica tão podre que não recebe pontuação. 
A meta é que o jogador fique re jogando para criar rotas mais criativas e conseguir pontuações melhores.

## Mecânicas principais

O jogador vai poder andar e pular pela tela, usando trampolins para ajudar a se locomover mais rápido.

Modo “Spice”. Terão vidros de molhos picantes espalhados na tela. Quando o jogador pegar o item para de ser infectado e  corre mais rápido por um período de tempo. Pegar os molho picante da um bônus de pontuação no final da tela.

A pontuação final será apresentada como “Nível de intoxicação alimentar”.

Com o decorrer do tempo a salsicha vai ficando verde e enrugada para dar o efeito visual.
